# Prairie Storytellers Guild Website

This is the official website for the Prairie Storytellers Guild, hosted on GitHub Pages.

## Local Development

To view and make changes to the website locally:

1. Navigate to the `prairietellers.github.io` directory in your Documents folder
2. Open `index.html` in your browser to see the current state of the website
3. Make your desired changes to the files
4. Test your changes by refreshing the browser

## Deploying Changes

After making changes to the website:

1. Open Cursor IDE
2. Ask Cursor to update the website using GitHub
3. Cursor will handle the git commands to:
   - Add the changes
   - Commit with a descriptive message
   - Push to the main branch

The changes will be automatically deployed to the live website at https://prairietellers.github.io

## File Structure

- `index.html` - Main website content
- `favicon/` - Website icons and favicon files
- `README.md` - This documentation file
